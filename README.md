# Zorif Properties Ltd Website Package

This ZIP package contains the complete, production-ready website for **Zorif Properties Ltd**.

## Folder Structure

```
zorif-properties-website/
│
├── index.html                  # Main responsive single-page corporate website
│
├── css/
│   └── style.css               # Clean navy-blue styling and custom layout rules
│
├── js/
│   └── script.js               # Form handling, validation, honeypot spam guard & dynamic year
│
├── downloads/
│   └── zorif-properties-company-brochure.txt  # Downloadable corporate brochure
│
└── README.md                   # Hosting and deployment instructions
```

## How to Test Locally
1. Extract the `.zip` archive.
2. Double-click `index.html` to open it directly in any web browser (Chrome, Edge, Safari, Firefox).
3. Test the Landlord and Investor forms, navigation links, and modals.

## Hosting & Domain Setup (zorifpropertiesltd.com)
- Connect this folder to your hosting provider (e.g. Netlify, Vercel, cPanel, Cloudflare Pages, or Apache/Nginx).
- **Domain Setting Notice:** When configuring DNS for `zorifpropertiesltd.com`, ensure MX and email records for `firoz@zorifpropertiesltd.com` remain intact and untouched.
